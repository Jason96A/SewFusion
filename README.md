# SewFusion project page

This repository hosts the coming-soon page for **SewFusion: Tailored Generation of Topology and Panel-Level Geometry for Sewing Patterns**.

Open `index.html` in a browser to preview it locally. The page is static and has no build step or external runtime dependencies. Its styles are in `static/css/index.css`.

The paper, code, and other research materials can be added when they are ready. Until then, the page shows only the project title, authors, affiliations, and a coming-soon notice.

Page design adapted from the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template).
